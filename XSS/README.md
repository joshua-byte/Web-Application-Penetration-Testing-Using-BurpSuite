# Cross-Site Scripting (XSS)

## Overview
This section contains practical XSS labs completed through PortSwigger Web Security Academy.

The exercises cover different types of Cross-Site Scripting vulnerabilities, their exploitation, and possible remediation techniques.

## Topics Covered
- Reflected XSS
- Stored XSS
- DOM-based XSS
- Context-specific XSS
- XSS filters and protections

## Tools Used
- Burp Suite
- Kali Linux
- Web Browser
- PortSwigger Web Security Academy
