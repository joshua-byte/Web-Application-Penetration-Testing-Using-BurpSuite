# File Upload Vulnerabilities

This repository contains notes and practical labs on file upload vulnerabilities.

## Topics Covered

- Unrestricted file uploads
- Content-Type spoofing
- File extension validation bypasses
- Path traversal
- File upload restrictions and bypass techniques

## Key Learnings

Understanding how file upload mechanisms work, identifying weak validation, testing upload restrictions, and recognising the security risks of improperly handled files.

## Tools Used

- Burp Suite
- PortSwigger Web Security Academy
