# Web Application Penetration Testing

A hands-on web pentesting focused on identifying, exploiting, analysing, and documenting vulnerabilities in web applications.

## Objectives

- Understand web application architecture and common security weaknesses.
- Identify vulnerabilities through systematic application testing.
- Analyse HTTP requests, responses, parameters, and application behaviour.
- Practise manual vulnerability discovery and exploitation.
- Evaluate security findings using CVSS.
- Map relevant adversarial techniques to MITRE ATT&CK.
- Develop professional penetration-testing reports with reproducible evidence.
- Understand remediation strategies and secure development practices.


## Assessment Methodology

Each assessment follows a structured approach:

1. Reconnaissance and application mapping.
2. Identification of potential attack surfaces.
3. Manual testing and vulnerability validation.
4. Controlled exploitation within authorized environments.
5. Technical analysis and impact assessment.
6. CVSS severity scoring and MITRE ATT&CK mapping where applicable.
7. Remediation recommendations.
8. Evidence collection and professional reporting.

## Documentation Standards

Assessments aim to include:

- Vulnerability description and technical explanation.
- Affected functionality and parameters.
- Reproduction methodology.
- HTTP request and response evidence.
- Security impact and exploitation prerequisites.
- CVSS scoring and justification.
- Relevant CWE and MITRE ATT&CK classifications.
- Recommended remediation.
