# Authentication Vulnerabilities

Authentication security assessments through PortSwigger Academy, intercepting, analysing, and manipulating HTTP requests.

## Tools Used
- Burp Suite Community Edition
- Web Browser
- Burp Intruder

## Key Concepts
- Username enumeration
- Authentication response analysis
- Password guessing
- Multi-factor authentication weaknesses
- Password reset vulnerabilities

## Documentation
Detailed assessment reports include technical analysis, evidence screenshots, impact assessment, and remediation recommendations.
